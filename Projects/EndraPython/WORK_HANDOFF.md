# Run014 handheld checks

Run013 is the confirmed hardware baseline. Run014 adds Files-first startup and a compact Pygame port.

```sh
clear
push /storage/emulated/0/Download/EndraPython_Run014.tns /upload
push /storage/emulated/0/Download/Run014_Pygame_Test.py.tns /upload
```

1. Open Run014. It starts with the file list. Use Menu > Browse Documents to reach upload.
2. Highlight Run014_Pygame_Test.py.tns. Right opens the editor. Esc returns to Files. Enter runs the highlighted script.
3. Hold Right to move the mint sprite into the yellow token. The token should disappear. Release the arrow to stop. Press Esc to see the frame count and token count. The script stops automatically at 240 frames.
4. Use Menu > New text file, make a note, save with Ctrl+S, and reopen it from Files.
