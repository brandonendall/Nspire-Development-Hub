# Run034 handheld check

Open the Python shell from the Files menu. The prompt should open with a blank output area. Enter `2+2`, `help()`, and `import os` followed by `os.listdir()`. Then enter `:help` and `:ls`. Both should show a Python syntax error and stay in the shell. Enter another expression afterward to confirm the session is still working.

Return to Files and run an existing script as before. Run033 is the last handheld-tested IDE fallback. Run034 host and CI checks are separate from the handheld check.
