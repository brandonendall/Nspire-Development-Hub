# Run035 handheld check

Transfer EndraPython_Run035.tns, Run035_Study_Check.py.tns and study_models.py.tns into the same Documents folder on the TI-Nspire. In Run035, browse to that folder, highlight Run035_Study_Check.py.tns and press Enter. Reply to the name prompt and press Enter. The final output should show “Run035 study checks passed”. The script writes two small sample data files named Run035_Study_Data.csv.tns and Run035_Study_Data.json.tns in its own folder.

The check uses a class from a separate file, a subclass with super(), a property, case conversion, f-strings, sets, collections, text files, CSV, JSON, statistics and input. Run035 also retains graphics, file browsing and the command catalog. For a handheld regression check, open the catalog in the shell and browse csv or statistics. Run your existing favorite Pygame script under Run035 before replacing an older build.

On a failure, capture the output line and keep the working build as a fallback. Run034 is the previous build and Run033 is the last separately confirmed IDE build in the hardware record.
