# Run013 cheat files
Run013 extends the Run012 Ndless emulator for TI-Nspire CX II CAS. A US Shining Soul II cartridge header (AU2E) gets a built-in one-shot Chaos Ring. With the top-left inventory slot empty, enable one item under Cheats and save options, resume, then check the inventory. Save in-game to keep it. Keep Run012 for rollback.

Put a plain-text file beside the game. For Game.gba.tns or Game.gbz.tns use Game.cht.tns. The first line is GAME followed by a space and the exact four-character cartridge ID. Each following line is Name=XXXXXXXX YYYYYYYY, containing an encrypted ARv3 direct RAM assignment. Prefix the name with ! to apply once. Ordinary entries repeat until turned off. Use left/right to toggle a slot; resume gameplay to apply. The file loads when the game opens; Reload cheat file refreshes it and disables all slots. Ten slots total, including built-ins. Labels use up to 16 letters, digits, spaces or basic punctuation. Import one code per line, and activate one item code at a time. The parser skips malformed entries and unsupported operations, including master codes, conditions, slides and multi-line sequences. Game data: https://tartarus.rpgclassics.com/ss2/ar3.htm
