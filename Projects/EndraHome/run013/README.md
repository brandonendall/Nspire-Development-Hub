# EndraHome Run013 — Assign from inside EndraHome

User confirmed Run012's one-press launch is very fast and requested assigning an app without typing paths manually. New feature: select dock icon, press **MENU** for its Info page, then **ENTER** for **ASSIGN APP**; browse folders under /documents with arrow keys, Enter opens folder, Enter on a .tns chooses it, Esc backs up or cancels (Menu cancels). For an unconfigured tile, Home Enter opens the picker directly. Successfully selecting a .tns saves the associated slot to the permanent EndraHome_Apps.cfg.tns file next to the launcher, so assignment survives restart. Other slot paths, custom labels and unrelated config lines/comments are retained.

**IMPORTANT: This is the first build that WRITES the configuration file.** It uses a temporary file and rename; on any failed save it leaves the existing configured file intact and reports a non-modal failure notice. Before first test, **make a backup of your existing EndraHome_Apps.cfg.tns** on Android or Nspire. Do not upload the blank template over your configured version. First test selecting the already-proven tiny EndraHome_Test006.tns on Tools. Existing Run012 (fast launch) and Run011 (auto return) are untouched backups.

Home: arrows select; Enter launches configured shortcut immediately; Menu shows Info. Info: Enter opens picker, Menu opens Help, Esc returns home. Browser: up/down move, right moves down a page, left or Esc goes up one folder, Enter opens a folder or assigns a .tns, Menu cancels. The picker is intentionally read-only; it cannot move/delete files. Only the chosen config shortcut is changed. It filters to folders and .tns files, limits listings to 768 items, and limits nesting/selected path length to the same safe 256-byte registry limit. It will never launch a file as part of browsing.

Physical test order: (1) Back up your configured config. (2) Keep Run012 installed. (3) Launch Run013, press Esc, verify quick exit. (4) Relaunch, Tools → Menu → Enter (Assign), browse to EndraHome_Test006.tns, press Enter once. (5) Verify non-modal SHORTCUT SAVED, Enter from Home launches immediately, and closing the child returns to EndraHome. (6) Exit/relaunch to confirm assignment remains. If the picker fails to open Documents, saving fails, hangs, or freezes, stop and revert to Run012; send photo or output before trying other applications.

Safe host tests include picker read-only traversal, .tns filtering, single-slot config write persistence and preservation of original comments/labels, and the proven auto-return logic. Device testing is pending: standard Ndless opendir/readdir/stat/rename support exists in repo's Commander, but the first picker device test has NOT yet happened.
