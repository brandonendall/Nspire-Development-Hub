# EndraHome project directory

The TI-Nspire launcher is developed on `feature/endrahome-run001`. Each numbered version has its own `Projects/EndraHome/runNNN/` directory on that branch. The [active project memory](https://github.com/brandonendall/Nspire-Development-Hub/blob/feature/endrahome-run001/Projects/EndraHome/PROJECT_MEMORY.md) records the latest source, build, and physical test reports.

Brandon’s installed Run028 Dynamic Launcher is preserved in the project.
