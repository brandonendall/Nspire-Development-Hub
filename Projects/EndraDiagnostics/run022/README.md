# EndraDiagnostics Run022 — bounded memory telemetry probe

Build on physical-tested Run021. Adds an **8 KiB application-owned malloc/read-write-verify/free probe**, performed once at startup after the established 4 KiB test. It reports PASS, N/A (allocation failed), or ERROR (integrity mismatch) on the RAM tab. This is genuine evidence about an 8 KiB application allocation **only**; it cannot measure free or used system RAM. CPU ID stability samples continue; no OS idle scheduler counter or CPU utilization API has been verified, so CPU load and both analog gauge needles remain N/A. Do not confuse application test success with system RAM capacity. Keeps read-only Documents scan, fast first paint, six tabs and exit. No direct arbitrary memory reads or system writes. Physical testing pending; keep Run021 for fallback.
