# Endra backlog — approved ambitions, not completed claims

## Integrated calculator experience
- EndraHome: seven customizable Ndless shortcuts, consistent polished theme; built-in Files browser plus user-selectable default apps. Eventually file/folder rename, copy, move, delete, read-only image view, text viewer/editor, JPG/PNG and PDF; prioritize safe bounded operations and smaller memory footprint.
- EndraCommander / Endra SDL: nCXplorer-like popup actions, recursive whole-folder copy/cut/paste and large files (~33MB), reliable parent/root handling, selectable external viewer/editor, friendly KB/MB/GB file sizes.
- EndraZIP: keep complete folder ZIP creation, extraction, CRC/security protections, responsive navigation, no duplicated footer.
- EndraGBA: stable full-speed emulator, GBZ compressed games, RTC, ROM-local saves, direct ROM launch if safely supported, readable folders-left/game-right browser, prompt fast exit.
- EndraDiagnostics: truthful CPU/system, RAM, storage, battery, LCD/keypad and USB diagnostics; avoid unsupported utilization readouts or destructive probing.

## Android software ecosystem
- EndraLink: safe multi-calculator file transport with Android USB device discovery, compatibility probes, reliable transfer, local file browser, debug logs and eventually integrated end-user management.
- EndraTermux: one-command phone installation of verified NLink/Push with complete source/licensing and documented USB recovery.
- EndraClean: reliable, user-controlled cache cleanup with permission clarity and STOP; never wipe app data.
- EndraSpell: accurate child-friendly spelling workflows, worksheet capture, individual learners, locally persisted progress and safe upgrades.
- EndraMath: supportive Pre-K-to-college adaptive curriculum, nonjudgmental skill mastery, optional dragon visual identity.
- EndraCanasta: responsive social tabletop prototype, eventual fair server-authoritative multiplayer across Android/iOS.
- PythonUltra: maintain compatibility across fx-CG50 display revisions, improve editor/files/ZIP/runtime help and documentation.

## Sharing with the community
- GitHub releases and checksummed binaries; public readmes, installation instructions, license compliance and source-to-binary traceability.
- Product website/landing page and community docs **concept**, not implemented here.
- Keep experimental, physically dangerous or unsigned/unverified builds marked TEST. Don't announce completion without actual user hardware acceptance.
